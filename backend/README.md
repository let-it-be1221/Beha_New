# Beha Backend — Laravel 12 API

The API half of the Beha Real Estate Management System. Serves:
- **`/api/v1/*`** — REST API (Sanctum-protected, consumed by the React SPA + future mobile apps)
- **`/admin`** — Filament v4 admin panel (sys-admin only)
- **`/`** — minimal welcome page listing endpoints

---

## Quick start

```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan storage:link
php artisan serve
```

The seeder prints a one-time temp password for `admin@beha.local`. Copy it — you'll need it for first login at `http://localhost:5173/login` (frontend) or `http://localhost:8000/admin` (Filament).

## Database

XAMPP MySQL defaults are in `.env.example`:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=beha_new
DB_USERNAME=root
DB_PASSWORD=
```

Create the database before migrating:

```bash
"C:\xampp\mysql\bin\mysql.exe" -u root -e "CREATE DATABASE beha_new CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```

Or via phpMyAdmin at <http://localhost/phpmyadmin>.

## Key commands

| Command | Purpose |
|---------|---------|
| `php artisan serve` | Start dev server on `:8000` |
| `php artisan migrate --seed` | Run all migrations + seeders |
| `php artisan migrate:fresh --seed` | Drop all tables + reseed (destructive) |
| `php artisan tinker` | REPL for inspecting models |
| `php artisan route:list` | List all registered routes |
| `php artisan config:clear` | Clear cached config (after .env changes) |
| `php artisan cache:clear` | Clear app cache |
| `php artisan permission:cache-reset` | Reset Spatie permission cache (after role/permission changes) |
| `php artisan storage:link` | Symlink `storage/app/public` → `public/storage` |
| `php artisan filament:install` | First-time Filament setup (run once) |
| `php artisan test` | Run Pest test suite |

## Environment variables

All sensitive / configurable values live in `.env`. Highlights:

```env
# App
APP_NAME="Beha API"
APP_URL=http://localhost:8000
FRONTEND_URL=http://localhost:5173

# Database (XAMPP defaults)
DB_DATABASE=beha_new
DB_USERNAME=root
DB_PASSWORD=

# SPA / Sanctum
CORS_ALLOWED_ORIGINS="http://localhost:5173,http://localhost:3000,http://localhost:8000"
SANCTUM_STATEFUL_DOMAINS="localhost,localhost:5173,localhost:8000,127.0.0.1,127.0.0.1:5173"
SESSION_DOMAIN=".localhost"
SESSION_SAME_SITE=lax

# Org identity (spec §5.1, §6)
OFFICIAL_ID_PREFIX=BH
OFFICIAL_ID_PAD_LENGTH=6
CUSTOMER_REF_PREFIX=CUS
ASSET_CODE_PREFIX=AST
CONFIDENTIAL_ID_FORMAT="{yy}-{GG}-{BB}-{TT}-{RR}"

# Capacity (spec §16)
TEAM_MEMBER_CAPACITY=10
TEAM_CAPACITY_PER_BRANCH=10
BRANCH_CAPACITY_PER_GENERATION=10

# Password policy (spec §25)
PASSWORD_MIN_LENGTH=12
PASSWORD_REQUIRE_MIXED_CASE=true
PASSWORD_REQUIRE_NUMBER=true
PASSWORD_REQUIRE_SYMBOL=true
TEMP_PASSWORD_TTL_HOURS=24
LOGIN_MAX_ATTEMPTS=5
LOGIN_DECAY_MINUTES=15
```

## API endpoints — full list

See the root README for the endpoint table. Highlights:

- `POST /api/v1/auth/login` — SPA cookie login
- `POST /api/v1/auth/token` — mobile API token
- `GET /api/v1/auth/me` — current user
- `POST /api/v1/auth/change-password` — change password (after first login)
- `GET /api/v1/customers`, `/properties`, `/applicants`, `/workflows`, `/evaluations`
- `POST /api/v1/applicants/apply` — public self-signup
- `POST /api/v1/workflows/{id}/advance` — workflow action

Run `php artisan route:list --path=api` to see all routes.
